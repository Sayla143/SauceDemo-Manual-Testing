# SauceDemo – Manual Testing Project

## 📌 Project Overview
This project focuses on manual testing of the SauceDemo e-commerce web application. The main objective is to understand the application's functionality, identify potential issues, and verify whether the application works as expected.

This project demonstrates practical knowledge of Software Quality Assurance (SQA) and manual software testing.

## 🎯 Project Objectives
- Understand the basic functionality of the SauceDemo application.
- Design and document test cases.
- Execute manual test cases.
- Verify actual results against expected results.
- Capture screenshots as testing evidence.
- Document test results for future reference.

## 🌐 Application Under Test
**Application Name:** SauceDemo  
**Website:** https://www.saucedemo.com/  
**Testing Type:** Manual Testing

## 🧪 Testing Activities
The following activities are included in this project:

- Test Planning
- Test Case Design
- Test Case Execution
- Expected vs. Actual Result Verification
- Screenshot Documentation
- Test Result Reporting
